# Fonts

Put OFL-licensed fonts here (with their licence file) to replace the default Aileron font:

- `Inter-Bold.ttf` and `Inter-Regular.ttf` (Inter, SIL Open Font License 1.1) are the files named in
  `config/brand.yaml` for slide headings and body text.
- Burned video captions use the family in `brand.yaml` → `design.video_font_family` (default `Inter`) when a
  font file with that name is in this folder.

Every font here is covered by the `templates/fonts/*` entry in `config/rights.yaml`. Only add fonts whose
licence allows embedding in images and video.
